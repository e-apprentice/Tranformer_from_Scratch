# Tranformer_from_Scratch

## Overview

This project is a from-scratch implementation of the Transformer architecture introduced in the landmark paper _Attention Is All You Need_ (2017). The primary goal of this project is to develop a deep understanding of Large Language Models (LLMs) by building their foundational architecture from first principles rather than relying on high-level libraries.

The implementation was developed by studying and referencing key resources, including:

- _Attention Is All You Need_ (Vaswani et al., 2017)
- _The Illustrated Transformer_ by Jay Alammar

Through this project, I explored the core components of the Transformer architecture, including token embeddings, positional encoding, self-attention, multi-head attention, feed-forward networks, residual connections, and layer normalization.

## Objectives

- Understand the mathematical foundations of Transformer models.
- Implement the Transformer architecture from scratch.
- Gain practical experience with attention mechanisms and sequence modeling.
- Build a strong foundation for studying and developing modern Large Language Models (LLMs).

## Features

- Token embedding layer
- Positional encoding
- Scaled dot-product attention
- Multi-head attention
- Feed-forward neural networks
- Residual connections and layer normalization
- Encoder–decoder Transformer architecture
- Training and inference pipeline

## Motivation

Large Language Models such as GPT, BERT, and T5 are built upon Transformer architectures. By implementing a Transformer from the ground up, this project aims to bridge the gap between theoretical understanding and practical implementation, providing valuable insights into the mechanisms that power modern AI systems.
